## 1. Learn

- Bucket
- Object
- Key
- Prefix
- Storage classes
- Versioning

- Event notifications

## 2. Data Lake structure

```text
s3://data-lake/
├── raw/
├── staging/
├── curated/
└── analytics/
```

Understand Bronze/Silver/Gold concepts.

## 3. File formats

Learn:

- CSV
- JSON
- JSON Lines
- Parquet
- Avro
- ORC

Know why Parquet is usually preferred for analytics.

## 4. Partitioning

Example:

```text
events/
  year=2026/
  month=09/
  day=28/
```

Learn:

- Partition pruning
- Partition cardinality
- Small files
- Over-partitioning
- High-cardinality partition problems

## 7. Python

Practice:

```python

s3.upload_file("data.csv", "my-bucket", "raw/data.csv")
```

- list_objects_v2
- get_object
- put_object
- copy_object
- delete_object
