# Sales Analytics Project

## Goal

Build a small analytical model around sales data and answer business questions such as:

- total revenue
- monthly sales trends
- top customers
- top products
- average order value
- repeat customers

---

## Core tables

Typical tables include:

- customers
- products
- orders
- order_items
- payments

---

## Key questions to answer

- What is total sales revenue?
- Which month had the highest revenue?
- Which customers spend the most?
- Which products sell best?
- What is the average order value?
- Which customers are repeat buyers?

---

## SQL skills used

This project helps practice:

- joins
- aggregations
- grouping by time
- window functions
- deduplication checks
- KPI reporting

---

## Suggested deliverables

Create a final reporting query set that returns:

- total sales
- monthly sales trend
- top customers
- top products
- average order value
- repeat customer rate

This is an excellent beginner-to-intermediate SQL analytics project.
